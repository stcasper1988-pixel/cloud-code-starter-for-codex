# TROUBLESHOOTING

Решения типовых проблем при настройке и работе с Codex. Если что-то не находишь - открой issue на GitHub.

## Установка и авторизация

### Не вижу Codex или команда `codex` не найдена

Для VS Code установи официальное расширение **Codex** и перезапусти окно: `Cmd/Ctrl + Shift + P` → `Developer: Reload Window`.

Для CLI установи Codex по [официальной инструкции](https://developers.openai.com/codex) и заново открой терминал. Не устанавливай непроверенные пакеты с похожими именами.

### Авторизация или доступ к модели не работает

Проверь по порядку:
1. Войди в Codex через поддерживаемый аккаунт ChatGPT или API key - способ входа зависит от твоего тарифа и клиента.
2. В CLI выполни `codex login` и следуй открытому окну авторизации; в IDE extension открой его панель и пройди вход там.
3. Проверь актуальные условия доступа в [официальной документации](https://developers.openai.com/codex/auth), а не по старым гайдам или скриншотам.
4. Если используешь API key - не вставляй его в проект, чат, `AGENTS.md` или `.codex/config.toml`.

### Project-local hooks не запускаются

Codex намеренно не исполняет hooks из незнакомого репозитория без доверия.

1. Открой `/hooks` в Codex.
2. Проверь `.codex/hooks.json`: должны быть `Stop`, `PermissionRequest`, `PreToolUse`.
3. Просмотри команды и **явно доверь** project-local hooks только после проверки.
4. Убедись, что policy script существует в `.codex/hooks/` и соответствует твоей ОС.
5. Перезапусти Codex и запусти микрозадачу для проверки звука.

### MCP из `.codex/config.toml` не подключается

1. Project-local MCP работает только в доверенном проекте.
2. Открой `/mcp` или выполни `codex mcp list` и прочитай точную ошибку.
3. Проверь, что секрет не записан в `config.toml`: используй `env_vars` или OAuth.
4. Проверь команду/пакет на странице официального MCP-провайдера, затем перезапусти Codex.

### В VS Code не вижу иконку Codex

1. Проверь, что установлено именно официальное расширение **Codex** (не GitHub Copilot и не сторонний форк).
2. Reload Window: `Cmd/Ctrl + Shift + P` → `Developer: Reload Window`.
3. Проверь, что расширение активировано: Extensions → Codex → Enable.

## Папки и файлы

### Не вижу `.business/` в сайдбаре VS Code

VS Code по умолчанию скрывает папки с точкой. В `.vscode/settings.json` этого шаблона уже прописано:

```json
{"files.exclude": {"**/.business": false}}
```

Если всё равно не видно - `Cmd/Ctrl + Shift + P` → `Developer: Reload Window`.

### У меня несколько бизнесов - как вести `.business/`?

Два подхода:
1. **Один проект на бизнес** - у каждого свой репо шаблона, своя `.business/`. Рекомендуется.
2. **Моно-репо с подпапками** - `./businesses/biz-1/.business/`, `./businesses/biz-2/.business/`. В `AGENTS.md` чётко укажи какой `.business/` читать в какой папке.

### Как перенести существующий проект в шаблон

Возьми промпт `prompts/methodology/import-existing-project.md` - Codex прочитает твой текущий код и заполнит `.business/` на основе того что найдёт.

## Работа с Codex

### Codex долго думает (>5-10 минут)

1. Подожди. Иногда на сложных задачах это нормально.
2. Если больше 10 минут - Esc → переформулируй промпт короче и конкретнее.
3. Не создавай новый чат ради «перезапуска» в середине задачи - потеряешь контекст. Если всё-таки начинаешь заново, сначала обнови план или ретро.

### Codex не понимает задачу

Признаки: отвечает общими словами, делает не то, путает файлы.
Причины:
1. Слишком длинный контекст. Используй `/compact`, если команда доступна в твоём клиенте, или закончи текущую задачу планом/ретро и открой новый чат.
2. Промпт слишком размытый. Добавь конкретику: файлы, примеры, критерий готовности.
3. Не прочитал `.business/INDEX.md`. Начни промпт с «сначала прочитай `.business/INDEX.md`».

### Режим полного доступа - надо или нет?

`--dangerously-bypass-approvals-and-sandbox` отключает approvals и sandbox. Удобнее, но опаснее.

**Не включай пока** не:
1. Сделал git-коммит (страховка - откат возможен).
2. Прошёл онбординг и понял, какие команды Codex выполняет.
3. Проверил и явно доверил `.codex/hooks.json`; policy script должен блокировать 4 категории команд (см. шаг 5 онбординга).

Если решишь включить его - сделай это сам в UI или CLI только на конкретную задачу. Шаблон никогда не должен включать режим автоматически.

### Поддерживаемые окружения

Шаблон рассчитан на **Codex IDE extension, Codex Desktop и Codex CLI**. `AGENTS.md` и `.agents/skills/` читаются Codex; project-local hooks и MCP требуют доверия к проекту. Для Claude Code используй [оригинальный репозиторий](https://github.com/artemiimillier/claude-code-starter).

### Голосовой ввод не работает

**Wispr Flow** (лучший на рынке, платный, Mac + Windows) - [wisprflow.ai](https://wisprflow.ai).
**Super Whisper** - альтернатива для Mac.
**Встроенный fallback:** Mac - System Settings → Keyboard → Dictation. Windows - `Win + H`.

Если Wispr не запускается на Mac - проверь разрешения: System Settings → Privacy → Microphone + Accessibility.

## Git и деплой

### `git commit` говорит «please tell me who you are»

Не настроен `user.name` или `user.email`. Локально для проекта:

```bash
git config user.name "Твоё Имя"
git config user.email "email@example.com"
```

### Случайно закоммитил `.env`

Сразу:
1. `git rm --cached .env`
2. Добавь `.env` в `.gitignore` (проверь что уже там).
3. `git commit -m "remove accidentally committed .env"`
4. **Если уже запушил в публичный репо** - **ротейт все ключи**, которые были в `.env`. Они скомпрометированы.

Для деплоя / платежей - см. `prompts/launch/`.
