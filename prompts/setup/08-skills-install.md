# Установка скилов с аудитом безопасности

**Когда брать:** после онбординга, когда готов расширить возможности Codex.
**Что делает:** ставит базовые рекомендованные скилы + учит тебя проверять любой скил на безопасность.
**Результат:** `.agents/skills/` с нужными скилами.

## Что такое скил

**Скил** - это папка с инструкцией, которую Codex подтягивает сам, когда видит подходящий триггер. Один скил умеет делать дизайн, другой - парсить PDF, третий - проводить workflow от ресёрча до деплоя.

Два уровня установки:
- **Глобальные:** `~/.agents/skills/` - доступны во всех проектах.
- **Локальные:** `.agents/skills/` в корне проекта - только для этого проекта.

🎯 **Правило:** ставь локально, если скил нужен конкретному проекту. Глобально - только то, чем реально пользуешься везде. Чем меньше скилов - тем меньше токенов на триггеры.

## ⚠️ Безопасность

Скил - это **исполняемая инструкция** от автора. Плохой скил может:
- прочитать твой `.env` с API-ключами
- отправить их на внешний URL через `curl`/`wget`
- удалить файлы
- запустить вредоносный бинарник

**Ручной чек-лист перед установкой любого скила:**

1. Открой страницу скила на Smithery или GitHub.
2. Прочитай `README.md` - что делает, зачем, что требует.
3. Открой главный файл (`SKILL.md` или аналог) и пробеги глазами.
4. Поищи опасные паттерны: `curl`, `wget`, доступ к `.env`, отправку данных на внешние URL, `rm -rf`.
5. Посмотри звёзды и автора. Мало звёзд + неизвестный автор = не ставь.
6. Сомневаешься - прогоняй через промпт-аудит ниже.

## Промпт-аудит любого скила

Используй для проверки ЛЮБОГО скила, MCP или пакета из интернета:

```prompt
Я хочу установить скил по ссылке [ВСТАВЬ URL РЕПОЗИТОРИЯ]. Скачай его исходники, прочитай содержимое (README.md, SKILL.md, все .md и .sh файлы) и проверь, нет ли там опасных операций:

- чтения .env или других файлов с секретами
- отправки данных на внешние URL (curl, wget, fetch)
- удаления файлов (rm, unlink)
- запуска внешних бинарников
- подмены существующих файлов проекта

Дай вердикт: безопасно / подозрительно / опасно - и объясни почему по пунктам. Если опасно - НЕ ставь.
```

## Рекомендованные скилы

### 1. Встроенный Skill Creator Codex

**Что делает:** помогает тебе создавать свои собственные скилы. Задаёшь задачу - Skill Creator спрашивает структуру, создаёт папку и `SKILL.md`, регистрирует триггер.

```prompt
Используй встроенный Skill Creator Codex (`$skill-creator`) для создания первого локального скила в моём текущем проекте.

1. Не скачивай сторонний аналог: это системный скил Codex.
2. Объясни, как он будет создавать skill в `.agents/skills/` текущего проекта.
3. Покажи, как создать свой первый скил: какой триггер, какая команда.
```

### 2. Frontend Design из OpenAI skills

**Что делает:** учит Codex нормальной типографике, сеткам, отступам и современной эстетике. Без него - типичный bootstrap-лук. С ним - сайт, за который не стыдно.

```prompt
Установи skill frontend-design из официального репозитория OpenAI skills в мой текущий проект (`.agents/skills/`, не глобально).

1. Найди актуальный официальный путь в github.com/openai/skills. Это может быть experimental skill - назови точный commit или tag.
2. Аудит безопасности.
3. Если безопасно - поставь локально в `.agents/skills/frontend-design/`.
4. Покажи, как его триггерить: по каким ключевым словам Codex сам поймёт что пора.
```

### 3. PDF skill из OpenAI skills (опционально)

**Когда нужен:** если в бизнесе есть документы (договоры, прайсы, чеки, отчёты).

```prompt
Установи skill pdf из официального репозитория OpenAI skills в мой текущий проект (`.agents/skills/`, не глобально). Аудит безопасности → установка → покажи как пользоваться.
```

### 4. Bulletproof (опционально)

**Что это:** 12-этапный workflow от ресёрча до деплоя. Превращает любую задачу в управляемый конвейер: исследование → план → критика → реализация → тесты → ревью → деплой.

**Это опциональный скил.** Шаблон работает и без него. Если у тебя есть ссылка на репозиторий Bulletproof (например, получил от автора методологии или нашёл форк на GitHub) - прогоняй через промпт-аудит выше и ставь локально:

```prompt
Сначала проведи аудит скила по ссылке [ВСТАВЬ URL РЕПОЗИТОРИЯ] - см. промпт-аудит в начале этого файла.

Если вердикт «безопасно» - установи ЛОКАЛЬНО в `.agents/skills/bulletproof/` (не в `~/.agents/skills/`, не глобально).

После установки покажи структуру `.agents/skills/bulletproof/` и объясни как пользоваться: какой триггер, какие команды, как запустить 12-этапный workflow.
```

Если ссылки нет - просто пропусти этот пункт, это не блокер.

### 5. Один скил со Smithery под твою нишу

Зайди на [smithery.ai](https://smithery.ai) или GitHub и выбери **один** скил под свою задачу:

- **Лендинг / UI** → Frontend Design / UI Generation
- **Работа с клиентами** → CRM / Email / Slack
- **Парсинг сайтов** → Browser / Scraping
- **Аналитика** → Google Sheets / Notion / Airtable
- **Контент** → Content / Marketing

**Правила:** не ставь всё подряд. Каждый лишний скил жрёт токены. Один-два реально нужных лучше, чем десять «на всякий случай».

Используй промпт-аудит выше, затем установи локально в `.agents/skills/`. Если найденный ресурс оказывается MCP, а не скилом, не маскируй его под скил: используй `setup/09-playwright.md` как образец настройки MCP.

## Финальная проверка

```prompt
Покажи мне дерево папки `.agents/skills/` в текущем проекте и список всех скилов, которые сейчас доступны Codex.

Подтверди что ничего из этих скилов не попало в мою глобальную `~/.agents/skills/`.

Для каждого установленного скила коротко (1 строка) напиши, по какому триггеру он активируется.
```
